# phys2d — патч: сцена в реальном времени

В архиве только изменённые и новые файлы. Распакуйте его поверх
`D:\projects\phys2d` с заменой.

| Файл | Что с ним |
|------|-----------|
| `examples/realtime_scene.cpp` | НОВЫЙ — интерактивная сцена (Win32 + GDI, без зависимостей) |
| `src/embedded_tables.S` | ЗАМЕНИТЬ — исправлена ошибка сборки под MinGW (COFF не допускает разность меток в `.quad`) |
| `CMakeLists.txt` | ЗАМЕНИТЬ — добавлена цель `phys2d_realtime` (линкуется с `gdi32 user32` на Windows) |

## Сборка и запуск (MSYS2 MinGW64)

```bash
cd /d/projects/phys2d
rm -rf build
cmake -B build -G "MinGW Makefiles" -DCMAKE_MAKE_PROGRAM=mingw32-make \
      -DCMAKE_BUILD_TYPE=Release -DPHYS2D_NATIVE=ON -DPHYS2D_SIMD_AVX=ON \
      -DPHYS2D_BIG_BINARY=ON -DPHYS2D_TABLE_MB=34
cmake --build build -j$(nproc)
./build/phys2d_realtime.exe
```

Быстро, без CMake и без встроенных таблиц:

```bash
cd /d/projects/phys2d
g++ -std=c++17 -O3 -march=native -Iinclude \
    examples/realtime_scene.cpp src/*.cpp -pthread -lgdi32 -luser32 \
    -o realtime.exe
./realtime.exe
```

На не-Windows системах тот же файл собирается в headless-режиме: прогон N секунд
симуляции, отчёт профайлера и `realtime_scene.json` (`./realtime 10`).

## Сцена

Арена 40x30 со стенами, две наклонные рампы, круглые и шестиугольные препятствия,
3 вращающиеся кинематические шестерни, цепочка из 8 звеньев на шарнирах,
пружинный маятник и 240 динамических тел (окружности, прямоугольники,
многоугольники, капсулы). Шаг фиксированный 1/60 с аккумулятором времени,
отрисовка через GDI с двойной буферизацией.

## Управление

| Клавиша | Действие |
|---------|----------|
| `SPACE` | пауза / продолжить |
| `S` | один шаг на паузе |
| `R` / `C` | пересобрать сцену / удалить все динамические тела |
| `1` `2` `3` `4` | создать окружность / прямоугольник / многоугольник / капсулу под курсором |
| ЛКМ | схватить и тащить тело (пружина в точке захвата) |
| ПКМ | взрыв в точке курсора |
| колёсико / стрелки | зум / панорама |
| `G` | гравитация вкл/выкл |
| `I` | переключить интегратор (symplectic Euler / Verlet / RK4) |
| `A` `N` `T` | AABB / контакты с нормалями / траектории |
| `M` `F` `E` `P` | многопоточность / трение / восстановление / позиционная коррекция |
| `[` `]` | меньше / больше итераций скоростного solver'а |
| `,` `.` | меньше / больше substeps |
| `J` `L` | сохранить / загрузить `scene.json` |
| `ESC` | выход |

В верхнем левом углу — HUD: FPS, время кадра и шага, тайминги всех стадий
(broad / narrow / velocity / position / constraints / sleeping), число тел, пар,
контактов и точек, вызовы GJK/EPA/SAT/TOI и попадания в кэш осей, полная
энергия системы, размер арены и состояние модулей.
