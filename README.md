# phys2d 

Заголовок `include/phys2d/Extras.h`,
шесть модулей реализации `src/Extras_*.cpp`, демо `examples/demo_v2.cpp`.

## Сборка (MSYS2 MINGW64)

```bash
cd /c/
cmake -B build -G "MinGW Makefiles" \
  -DCMAKE_MAKE_PROGRAM=mingw32-make \
  -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ \
  -DCMAKE_BUILD_TYPE=Release \
  -DPHYS2D_NATIVE=ON -DPHYS2D_SIMD_AVX=ON -DPHYS2D_FMA=ON \
  -DPHYS2D_BIG_BINARY=ON -DPHYS2D_TABLE_MB=34
cmake --build build -j$(nproc)

./build/phys2d_demo_v2.exe --steps 240        # демо всех подсистем
./build/phys2d_demo_v2.exe --benchmark        # 11 сцен + отчёт
./build/phys2d_realtime.exe                   # окно реального времени
```

Без CMake:

```bash
g++ -std=c++17 -O3 -march=native -Iinclude examples/demo_v2.cpp src/*.cpp -pthread -o demo_v2.exe
```

## Точка входа: класс Engine

`Engine` владеет миром и всеми подсистемами; `step(dt)` прогоняет их в правильном порядке.

```cpp
#include "phys2d/Extras.h"
using namespace phys2d;

Engine engine;
engine.fracture().enabled = true;          // разрушение
engine.softBodies().enabled = true;        // мягкие тела
engine.fluid().enabled = true;             // SPH
engine.fields().enabled = true;            // поля
engine.fields().flags = FIELD_WIND | FIELD_NBODY;

for (int i = 0; i < 600; ++i) engine.step(1.0 / 60.0);
std::puts(engine.statusLine().c_str());
```

Все подсистемы включаются/выключаются флагом `enabled`, доступны и по отдельности
(без `Engine`): достаточно вызвать `attach(world)` и `update(dt)`.

## Приближения и ограничения

| Требование | Как сделано |
|---|---|
| Lua-скриптинг | собственный интерпретатор (переменные, выражения, `if`, `repeat`, команды) — без внешней зависимости от Lua |
| Remote-консоль | консоль на опросе файла команд вместо TCP-сервера |
| CUDA | не включено; параллелизм через пул потоков и острова |
| OpenGL с шейдерами, теневая карта, 3D-параллакс | отрисовка через Win32/GDI (`phys2d_realtime`) и SVG-дебаг; шейдерного бэкенда нет |
| Звук с Доплером | синтез в буфер и экспорт WAV; воспроизведения в реальном времени нет |

## Найденные и исправленные баги (этот этап)

1. **Soft weld joint расходился** при малом шаге: коэффициент `gamma` не входил
   в эффективную массу. Проявлялось только вместе с быстрыми телами (шестернями),
   включающими substepping. Исправлено в `WeldJoint::prepare`.
2. **Шум Перлина возвращал мусор** при больших координатах — `(int)std::floor(x)`
   переполнялся. Ветер выдавал бесконечную силу. Добавлены проверка конечности
   и свёртка координат.
3. **Ветер разгонял лёгкие звенья цепей**: добавлен предел ускорения
   `FieldSystem::maxWindAcceleration` (250 м/с² по умолчанию).
4. **Связка мягких и твёрдых тел**: импульс ограничен меньшей из двух масс,
   добавлены проверки на нефинитные состояния.

Остаточное замечание: в максимально плотной демо-сцене (трос + шестерни + жидкость +
мягкие тела + все поля одновременно) `SafetyGuard` ещё изредка чинит одиночные NaN
на звеньях троса. Симуляция при этом остаётся устойчивой, энергия не растёт,
но если нужна абсолютная чистота — отключите ветер для тонких цепей
(`FIELD_WIND` или `maxWindAcceleration` поменьше).
