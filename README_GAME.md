# GORE LAB — физическая песочница на phys2d

Игра-песочница поверх движка: рэгдоллы, разрушаемые ящики, дробилки-шестерни,
мягкое тело, SPH-жидкость, верёвка с ядром — и детализированная система крови.

## Файлы

| Файл | Что это |
|---|---|
| `include/phys2d/Blood.h` | API системы крови (`BloodSystem` наследует `SimulationSystem`) |
| `src/Blood.cpp` | реализация: капли, декали, лужи, раны, пульс, свёртывание |
| `examples/sandbox_game.cpp` | сама игра: арена, оружие, рендер Win32/GDI + headless-режим |
| `CMakeLists.txt` | добавлена цель `phys2d_sandbox` и `src/Blood.cpp` в библиотеку |

## Сборка (MSYS2 MINGW64)

Без `-march=native`, пока не разобрались с `Illegal instruction` на GCC 16:

```bash
cd /d/projects/phys2d
rm -rf build
cmake -B build -G "MinGW Makefiles" -DCMAKE_MAKE_PROGRAM=mingw32-make \
      -DCMAKE_BUILD_TYPE=RelWithDebInfo \
      -DPHYS2D_NATIVE=OFF -DPHYS2D_SIMD_AVX=OFF -DPHYS2D_SIMD_SSE=OFF \
      -DPHYS2D_FMA=OFF -DPHYS2D_BIG_BINARY=OFF
cmake --build build -j$(nproc) --target phys2d_sandbox
./build/phys2d_sandbox.exe
```

Без CMake, одной строкой:

```bash
g++ -std=c++17 -O2 -Iinclude examples/sandbox_game.cpp src/*.cpp -pthread -lgdi32 -luser32 -o gore_lab.exe
```

На Linux/без Windows тот же исходник собирается в headless-режим:
`./gore_lab --steps 900` прогоняет скриптовую бойню, печатает статистику и
пишет `gore_frame.svg` — векторный снимок сцены со всеми пятнами.

## Управление

| Клавиша | Действие |
|---|---|
| `1` | схватить тело мышью (пружинный захват) |
| `2` / `3` / `4` | заспавнить ящик / бочку / жертву-рэгдолла |
| `5` | лезвие: режет плоть по движению мыши |
| `6` / `7` | пуля (рейкаст навылет) / дробовик, 9 картечин |
| `8` | граната (правая кнопка мыши — тоже граната) |
| `9` / `0` | брандспойт с водой / шланг с кровью |
| ЛКМ | применить инструмент, удерживание = непрерывно |
| колесо | зум, стрелки — камера |
| `SPACE` / `S` | пауза / один шаг |
| `R` / `C` | пересобрать арену / стереть всю кровь |
| `B` `D` `F` | кровь / декали / жидкость вкл-выкл |
| `T` / `G` | слоу-мо x0.25 / выключить гравитацию |
| `[` `]` | итерации солвера -2 / +2 |
| `ESC` | выход |

## Что «выжимает» из движка

- рэгдоллы на ломких суставах (`BreakableJointSystem`) — отрыв конечностей;
- `FractureSystem` — ящики раскалываются по Вороному от импульса;
- `SoftBodySystem` — мягкое тело с разрывом (`tearStrain = 0.85`);
- SPH-жидкость с доменом, кинематические шестерни-дробилки и вертушка;
- катенарная цепь с чугунным ядром, пирамида ящиков (тест стабильности стека);
- рейкасты навылет с потерей энергии в плоти (x0.45) и в хрупком (x0.35);
- взрывы через импульс по радиусу + инициирование разломов.

## Система крови

Модель: кровь — это объём в миллилитрах, который перетекает между тремя
состояниями: **капли в воздухе → декали на поверхностях → лужи на полу**.

- **Раны** (`addWound` / `sever`) имеют резервуар, тяжесть и свёртывание;
  артериальные пульсируют — `pulseHz = 1.30`, сила пульса `0.85`,
  струя идёт по `beat³`, то есть короткими выбросами, как из настоящей артерии.
- **Капли** — верле-интеграция с квадратичным сопротивлением; траектория
  трассируется рейкастом движка, так что капля попадает ровно в то тело,
  через которое пролетела, а не проваливается сквозь него на большой скорости.
- **Декали** лежат в локальных координатах тела: пятно едет и крутится вместе
  с телом. Форма — рваный многоугольник из `splatterLobes = 9` лепестков,
  вытянутый по касательной при скользящем ударе, с «хвостом» по направлению
  полёта и мелкими спутниками-брызгами при скорости выше `castOffSpeed`.
- **Лужи** сливаются в радиусе `poolMergeDist`, растут как `sqrt(V)`, сохнут за
  `poolDryTime = 70 s`.
- **Цвет** зависит от насыщения кислородом (артериальная 235 — алая, венозная
  190 — тёмная) и от степени высыхания: свежая → бурая корка.
- **Мокрота тел** (`stainBody`) размазывается при движении (`smearRate`) и
  капает вниз (`dripRate`) — залитый кровью рэгдолл оставляет следы.

Лимиты по умолчанию: 24000 капель, 7000 декалей, 900 луж, 256 ран —
старые перерабатываются, память не растёт.

Основные ручки настройки: `airDrag`, `stickiness`, `bounceRestitution`,
`castOffSpeed`, `clotRate`, `dryTime`, `poolSpread`, `enableMist`,
`enableCastOff`, `enablePools`, `groundLevel`.

### Минимальное использование

```cpp
phys2d::Engine engine{cfg};
phys2d::BloodSystem blood;
blood.attach(engine.world());
blood.groundLevel = 0.02;

blood.addWound(bodyId, worldPoint, worldNormal, /*severity*/0.8, /*arterial*/true);

for (;;) {
    engine.step(dt);
    blood.update(dt);   // после шага мира
}
```
